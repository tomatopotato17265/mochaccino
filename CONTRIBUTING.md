# Contributing to Mochaccino

Thank you for wanting to contribute to Mochaccino! Here are some tips and info to help you get started with contribution.

## Project Information

Mochaccino is mostly written in Java for easy compatibility with Minecraft: Java Edition and multiple mod loaders. However, there is some Swift code that is required for Mochaccino's notifications.

## Setting up a local repository

Begin by cloning the repository in a directory of your choice:
```
git clone https://github.com/tomatopotato17265/mochaccino
cd mochaccino
```

You can now open the project in an IDE of your choice. We recommend using [IntelliJ IDEA](https://www.jetbrains.com/idea/), as it is a powerful IDE for Minecraft mod development.

That's it! You can now start editing the code and making any changes you'd like. When you're ready to share them, create a [Pull Request](https://github.com/tomatopotato17265/mochaccino/pulls). Thank you for helping us improve Mochaccino!

# Mochaccino

Mochaccino is a mod for Minecraft: Java Edition that adds native Menu Bar and Dock features on macOS.

The name Mochaccino was inspired by the coffee-and-chocolate drink, with Java as the coffee and Cocoa (Apple's macOS framework) as the chocolate. This mod blends the two to give Minecraft a native menu bar and Dock on macOS.

## Download

You can download Cloudify from [Modrinth](https://modrinth.com/project/mochaccino) or from this repository's [Releases](https://github.com/tomatopotato17265/mochaccino/releases/latest).

## Features

- Do stuff from the Menu Bar
  - View and switch between mods and resource packs
  - Create new worlds
- Change the app icon
  - Set a custom image
  - Add a macOS squircle background
- Notifications
  - Receive notifications when your game needs to be restarted

# Mochaccino

Mochaccino is a mod for Minecraft: Java Edition that adds native Menu Bar and Dock features on macOS.

The name Mochaccino was inspired by the coffee-and-chocolate drink, with Java as the coffee and Cocoa (Apple's macOS framework) as the chocolate. This mod blends the two to give Minecraft a native menu bar and Dock on macOS.
